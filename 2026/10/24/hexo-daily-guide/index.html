这台博客的日常使用手册

2026-10-24 · 博客维护 · #博客维护 · #教程

这台博客由自制引擎驱动（零依赖，一个 build.js），并且带了一个网页写作后台——写文章、预览、发布，全程不用碰命令行。

首选方式：网页写作后台

第一步，启动本地服务（只需做一次，之后一直开着就行）：在 E:\blog\site 下运行 npm run serve（或双击运行 start-blog.bat）。

然后浏览器打开 http://localhost:5555/admin/ ，就进入了写作后台：

  • 左边是文章列表，点任意一篇就能载入修改；
  • 中间是编辑器：标题、文件名、日期、分类、标签自动组装成 front-matter，正文直接写 Markdown；
  • 右边是实时预览，写公式 $E=mc^2$、代码块、表格都能即时看到渲染效果（和线上完全一致，因为用的是同一个渲染器）；
  • 顶部按钮：保存（快捷键 Ctrl+S）→ 存到 posts 目录；保存并构建 → 立即更新本地站点；🚀 发布上线 → 一键推送到 GitHub，约一分钟后 <https://ljy600.github.io> 生效；
  • 勾选草稿后保存的文章不会出现在站点上，想删除文章就载入它然后点删除本文。

整个流程：打开后台 → 写 → 点发布。完事。

备用方式：命令行

后台的本质是操作 posts\ 目录里的 .md 文件，所以直接管理文件也完全可以：

想做什么位置 / 命令
写新文章E:\blog\site\posts\ 新建 .md（或用后台写）
构建npm run build
本地预览npm run serve → http://localhost:5555
发布上线npm run deploy
站点配置E:\blog\site\site.json
主题样式E:\blog\site\assets\style.css
引擎本体build.js（生成器）serve.js（预览+后台）markdown.js（渲染器）

手写文章的 front-matter

---
title: 文章标题
date: 2026-10-24 11:00:00
categories: 分类
tags: [标签1, 标签2]
draft: true
---

各字段都可选（draft: true 表示草稿，不构建）。

小技巧

  • 摘要截断：正文里单独一行写 `

`，首页只显示它之前的内容，附"阅读全文"链接。

  • 公式：行内 $...$，独立公式 $$...$$（单独成行），详见《在文章里写数学公式》。
  • 写作后台只在本机可访问（只监听 127.0.0.1），不会被局域网或互联网访问到，请放心。
