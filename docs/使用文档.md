## 一、博客是怎么工作的

整站由一套**自制零依赖引擎**驱动（只用 Node.js 内置模块，没有任何 npm 包），托管在 GitHub Pages 上，完全免费。

```
写文章（网页 /admin/ 或本地后台）
   │  保存 = 提交 Markdown 源文件
   ▼
GitHub 仓库 main 分支（posts/*.md、pages/*.md、site.json）
   │  推送自动触发
   ▼
GitHub Actions 云端构建（运行 build.js）
   │  生成整站静态文件
   ▼
gh-pages 分支 → GitHub Pages 对外服务
   ▼
https://ljy600.github.io （约 1-2 分钟后生效）
```

关键设计：**文章源文件（Markdown）与构建产物分开存放**。网页端和本地端编辑的是同一份源文件，不会互相覆盖。

## 二、快速上手：三种写作方式

| 方式 | 适合场景 | 步骤 |
|---|---|---|
| **网页后台**（推荐） | 任何设备、随手写 | 打开 `/admin/` → 写 → Ctrl+S 发布 |
| **本地后台** | 在自己电脑上、离线可写 | 双击 `E:\blog\site\start-blog.bat` → 打开 `localhost:5555/admin/` → 写 → 🚀 发布上线 |
| **命令行** | 批量操作、熟悉终端 | 编辑 `posts\*.md` → `npm run deploy` |

三者操作的是同一批文件，可随时混用。

## 三、网页写作后台详解

地址：<https://ljy600.github.io/admin/>

```
┌──────────────────────────────────────────────────────┐
│ ✍️ 写作   ＋新文章    [令牌栏-仅首次]   保存并发布  看博客↗ │
├──────────┬───────────────────────────────────────────┤
│ 文章列表  │  标题 | 文件名 | 日期                       │
│ (点击载入)│  分类 | 标签 | ☐置顶 ☐草稿                  │
│          │ ┌──────────────┐ ┌──────────────┐          │
│ 按时间倒序│  │ 正文 Markdown │ │  实时预览     │          │
│ 草稿有标记│  │              │ │ (公式/代码同线上)│        │
└──────────┴──┴──────────────┴─┴──────────────┴──────────┘
```

- **保存并发布（Ctrl+S）**：在线模式下保存即提交 GitHub 并自动构建，编辑器会轮询显示构建进度（需要令牌有 Actions 只读权限）；构建完成会提示刷新博客。
- **实时预览**：浏览器里跑的就是构建器用的同一份渲染器（`markdown.js`），公式、代码高亮所见即所得。
- **置顶**：勾选后文章带渐变徽章、排到首页最前（多篇置顶时内部仍按时间排序）。
- **草稿**：勾选后文章仍在仓库里，但构建时跳过，不会出现在站点上。
- **删除本文**：删除当前载入的文章（不可恢复）。
- **文件名**：即文章链接标识符，建议英文/数字/连字符，如 `my-first-post` → 链接 `/2026/10/24/my-first-post/`。

本地后台（`localhost:5555/admin/`）界面相同，额外多一个「🚀 发布上线」按钮（把源码推给 GitHub 构建本地未同步的改动）。

## 四、首次使用：创建 GitHub 令牌

网页编辑器保存文章需要一把"临时密码"（令牌）来以你的身份写入仓库。只需设置一次，之后浏览器会记住。

1. 登录 GitHub，打开：<https://github.com/settings/personal-access-tokens/new>
   （手动路径：头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token）
2. 填写：
   - **Token name**：随意，如 `blog-editor`
   - **Expiration**：90 天或 1 年（到期重新生成即可）
   - **Repository access**：**Only select repositories** → 选 `Ljy600/Ljy600.github.io`
   - **Permissions → Repository permissions**：
     - **Contents → Read and write**（必须，读写文章）
     - **Actions → Read-only**（可选，显示构建进度）
3. **Generate token**，复制生成的 `github_pat_...` 字符串（**只显示一次**）。
4. 回到编辑器，粘贴到顶部输入框 → 「连接」。

**安全性**：令牌只存在你自己浏览器的 localStorage；权限仅限这一个仓库；随时可在同一页面删除令牌使其失效。

## 五、布局与页面管理台

地址：<https://ljy600.github.io/admin/layout/>（文章编辑器顶部「🎨 布局与页面」可跳转）

### 5.1 界面布局

| 控制项 | 选项 | 对应 site.json 字段 |
|---|---|---|
| 头部位置 | 居左 / 居中 | `layout.headerStyle: "left" \| "center"` |
| 头部吸顶 | 开 / 关 | `layout.stickyHeader` |
| 首页大标题区 | 开 / 关 | `layout.hero` |
| 文章列表样式 | 列表式 / 卡片式 | `layout.listStyle: "list" \| "card"` |
| 页脚 | 开 / 关 | `layout.footer` |
| 阅读时长 | 开 / 关 | `layout.readingTime` |

### 5.2 导航菜单

- 每一项可改名、改链接（支持站内路径 `/archives/` 和外部链接 `https://...`）
- ↑ ↓ 调整顺序，✕ 删除，＋ 添加
- 保存后全站导航立即按新顺序渲染

### 5.3 独立页面

- **新建页面**：填标题、文件名（= 链接 `/文件名/`）、Markdown 内容，勾选"保存后加入导航菜单"
- **编辑 / 删除**：页面列表中的 ✎ / ✕ 按钮（删除页面会同时从导航移除对应项）
- 页面和文章的区别：页面不进文章列表、不显示日期标签，适合"关于""友链"等固定内容
- 内置页面：「关于」`/about/`、示例「友情链接」`/links/`（不需要可在面板删除）

### 5.4 保存机制

- **在线模式**：点「保存布局并发布」→ 写回仓库的 `site.json` / `pages/*.md` → Actions 自动构建 → 1-2 分钟生效
- **本地模式**：同按钮 → 写回本地文件并立即构建，刷新 `localhost:5555` 预览

## 六、外观设置面板（访客功能）

博客**右上角 ⚙ 按钮**，任何访客都能调：

| 设置 | 选项 | 说明 |
|---|---|---|
| 主题色 | 青(默认)/蓝/紫/玫红/琥珀/绿 | 全站主色即时切换 |
| 内容宽度 | 紧凑 680 / 适中 768 / 宽敞 920px | 正文版心宽度 |
| 正文字号 | 小 / 中 / 大 | 只影响文章正文 |
| 深色模式 | 自动 / 浅色 / 深色 | 自动=跟随系统；手动时代码高亮同步切换 |

- 所有选择保存在**访客自己的浏览器**（localStorage），一键"恢复默认"
- 站长在 `site.json → theme` 里设的默认值会被访客的选择覆盖

## 七、写作语法速查

### 7.1 front-matter（文章开头的元信息）

```yaml
---
title: 文章标题            # 必填
date: 2026-10-24 11:00:00 # 可选，默认保存时间
categories: 分类名         # 可选，单分类
tags: [标签1, 标签2]        # 可选，多个标签
sticky: true               # 可选，置顶
draft: true                # 可选，草稿（不构建）
---
```

（网页编辑器里这些都会自动组装，手写文件时才需要记住。）

### 7.2 Markdown 基础

| 写法 | 效果 |
|---|---|
| `# 标题`（1-6 个 #） | 各级标题（≥3 个小标题自动生成文章目录） |
| `**粗体**` `*斜体*` | 粗体 / 斜体 |
| `` `行内代码` `` | 行内代码 |
| <code>```语言 … ```</code> | 代码块（自动高亮，悬停可复制） |
| `[文字](https://...)` | 链接（外链新标签页打开） |
| `![描述](图片地址)` | 图片 |
| `- 项目` / `1. 项目` | 无序 / 有序列表 |
| `\| 表头 \| 表头 \|` | 表格（第二行写 `\|---\|---\|`） |
| `> 引用文字` | 引用块 |
| `---`（单独一行） | 分隔线 |
| `<!--more-->`（单独一行） | 截断首页摘要，后文折叠进"阅读全文" |

### 7.3 数学公式

- 行内：`$E = mc^2$`
- 独立成行：`$$` 单独一行开始、公式、`$$` 单独一行结束
- 高级结构支持 `\begin{cases}`（分段）、`\begin{aligned}`（对齐推导）、`\begin{pmatrix}`（矩阵）等
- 详见博客文章《在文章里写数学公式》
- 注意：公式内不要有空行；正文写美元金额用 `\$` 转义

## 八、站长配置参考（site.json）

位置：`E:\blog\site\site.json`（或布局台可视化修改）。改完推送/保存构建后生效。

```jsonc
{
  "title": "Ljy600's Blog",        // 站名
  "subtitle": "记录与分享",          // 副标题（站名旁边）
  "description": "……",             // 站点描述（SEO + Hero 副标题）
  "author": "Ljy600",              // 作者名（页脚、RSS）
  "url": "https://ljy600.github.io",
  "nav": [                          // 导航菜单（布局台可改）
    { "label": "首页", "href": "/" }
  ],
  "layout": {                       // 布局开关（见第五节）
    "headerStyle": "left",
    "stickyHeader": true,
    "hero": true,
    "listStyle": "list",
    "footer": true,
    "readingTime": true
  },
  "theme": {                        // 访客自定义之前的全站默认外观
    "accent": "",                   // 默认主题色，如 "#2563eb"，留空用内置青
    "width": "m",                   // s / m / l
    "font": "m",                    // s / m / l
    "hero": true
  }
}
```

## 九、常见问题与故障排查

| 问题 | 处理 |
|---|---|
| 编辑器提示"令牌无效或权限不足" | 令牌过期或没给 Contents 写权限 → 按第四节重新生成并连接 |
| 保存后提示文件冲突 | 文章在 GitHub 上有更新（比如另一台设备改过）→ 重新载入该文章再编辑 |
| 保存后线上没变化 | 1-2 分钟构建期属正常；编辑器状态栏会显示构建进度。可在 <https://github.com/Ljy600/Ljy600.github.io/actions> 看构建记录 |
| 本地预览打不开 | `start-blog.bat` 窗口是否开着？端口占用就换一个：`node serve.js 5556` |
| 布局改坏了想还原 | 布局台逐项调回，或把 `site.json → layout` 整段删除（用默认值） |
| 公式显示原始代码 | 检查 `$` 是否成对、`$$` 是否单独成行；刷新页面等 MathJax 加载完 |
| 文章顺序不对 | 列表按"置顶优先 + 时间倒序"；确认 front-matter 的 date 格式正确 |
| 本地与线上内容不一致 | 本地改完没推送：本地后台点「🚀 发布上线」或命令行 `npm run deploy` |

**紧急回退**：博客曾用 Hexo 搭建，旧目录 `E:\blog\myblog` 原样保留。如需回退：在那边执行 `hexo clean && hexo g && hexo d`，并在仓库 Settings → Pages 把分支切回 main。

## 十、文件结构参考

```
E:\blog\site\                ← 整个目录就是一个 Git 仓库（main 分支）
├── posts\                   文章（.md，文件名 = 链接标识符）
├── pages\                   独立页面（about.md、links.md）
├── assets\                  主题 style.css、favicon、admin.html（文章编辑器）、layout.html（布局台）
├── docs\                    本文档
├── site.json                站点配置（导航/布局/主题默认值）
├── markdown.js              Markdown 渲染器（构建器与浏览器预览共用同一份）
├── build.js                 静态站点生成器 → dist\
├── serve.js                 本地服务器：静态站点 + 本地后台 API（仅本机可访问）
├── deploy.js                推送源码到 GitHub（触发云端构建）
├── start-blog.bat           双击启动本地写作环境
├── .github\workflows\deploy.yml   Actions：push main → 自动构建 → 发布 gh-pages
└── dist\                    本地构建产物（不入仓库）
```

常用命令：

| 命令 | 在 `E:\blog\site` 下执行 | 作用 |
|---|---|---|
| `npm run serve` | ✓ | 构建 + 本地预览/后台（localhost:5555） |
| `npm run build` | ✓ | 只构建 |
| `npm run deploy` | ✓ | 推送源码，云端自动构建发布 |
